# بسته ساخت APK اندروید — تعمیرات تهران آنلاین

این پروژه دو APK مستقل می‌سازد: اپ مشتری و اپ تکنسین. محتوای HTML فعلی در هر برنامه به‌صورت آفلاین داخل WebView اجرا می‌شود.

## ساخت با GitHub از طریق گوشی
1. این ZIP را از حالت فشرده خارج کنید.
2. در GitHub یک مخزن جدید و خالی بسازید؛ نام پیشنهادی `TehranOnline-Android`.
3. تمام محتویات پوشه این پروژه را در ریشه مخزن بارگذاری کنید (پوشه `.github` نیز باید بارگذاری شود).
4. وارد تب **Actions** مخزن شوید و گردش کار **Build Android APKs** را اجرا کنید؛ در اولین بار ممکن است لازم باشد Actions را فعال کنید.
5. پس از موفقیت، در همان اجرای workflow بخش **Artifacts** فایل `TehranOnline-Android-APKs` را دریافت کنید. ZIP حاصل شامل دو APK است.

## محدودیت مهم نسخه 0.1.0
این‌ها APKهای نصب‌پذیرِ بسته‌بندی‌شده از پیش‌نمایش‌های فعلی هستند، نه نسخه عملیاتی نهایی. HTML فعلی و ذخیره‌سازی محلی آن به‌تنهایی اتصال به API، حساب کاربری واقعی، همگام‌سازی سفارش‌ها بین مشتری و تکنسین، پرداخت، پیامک یا اعلان را فراهم نمی‌کند. برای فعال شدن این موارد باید بک‌اند بررسی، ایمن‌سازی و مستقر و سپس دو رابط به API متصل شوند.

## مشخصات فنی
- دو برنامه و شناسه بسته مستقل
- حداقل Android 6.0 (API 23)
- ساخت Debug برای آزمایش؛ برای انتشار عمومی باید امضای Release امن و آزمون‌های امنیتی/عملکردی انجام شود.
- هیچ رمز یا کلید محرمانه‌ای در این بسته قرار داده نشده است.
